# fc-ddd-patterns

Implementação do desafio **DDD: Repository e Testes** do curso Full Cycle.

## Requisitos

- Node.js >= 16
- npm >= 8

## Instalação

```bash
git clone <url-do-repositorio>
cd fc-ddd-patterns
npm install
```

## Executando os testes

```bash
npm test
```

Todos os testes rodam com SQLite em memória — nenhuma configuração de banco de dados é necessária.
